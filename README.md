# BBM126 Exploratory Data Analysis Project

Exploratory Data Analysis project for BBM126: Programming for Data Analytics at Aston University.
This Jupyter Notebook uses Python to clean, explore, visualise, and model a real world dataset, including statistical tests and linear regression.

## Contents
1. `EDA_abi.ipynb`: main analysis notebook.
2. Data visualisations and statistical tests.
3. Linear regression model with interpretation.

## How to Run
1. Install Python and Jupyter Notebook.
2. Install required libraries: pandas, numpy, matplotlib, seaborn, and statsmodels (or as used).
3. Open `EDA_abi.ipynb` in Jupyter and run all cells.
